SITE DEMONSTRATIVO — KEITIANE BARBOSA | ADVOCACIA
====================================================

COMO VISUALIZAR
1. Extraia a pasta/arquivo ZIP.
2. Abra index.html em um navegador atualizado.
3. Para uma apresentação melhor, use a tela cheia do navegador.

ARQUIVOS
- index.html: estrutura, estilos CSS e JavaScript do site.
- assets/logo-keitiane-barbosa.png: logotipo enviado pelo cliente.
- assets/foto-escritorio-provisoria.jpg: imagem ilustrativa de escritório jurídico enviada como referência.
- referencia-layout.jpg: referência visual recebida; não é usada como conteúdo do site.

PERSONALIZAÇÃO
- Logotipo: substitua assets/logo-keitiane-barbosa.png mantendo o mesmo nome, ou altere o caminho no HTML.
- Fotografias: substitua assets/foto-escritorio-provisoria.jpg por uma foto autorizada, mantendo o nome, ou atualize os caminhos e textos alternativos no HTML. A foto é ilustrativa e não representa Keitiane Barbosa.
- Cores e fontes: no início do <style> do index.html, altere as variáveis CSS dentro de :root (por exemplo --navy, --gold, --cream).
- Textos: procure as seções identificadas por comentários no HTML e substitua os textos demonstrativos.
- WhatsApp: no fim do index.html, localize const WHATSAPP_NUMBER = ""; e informe o número completo com código do país e DDD, apenas números. Exemplo de formato: 5563999999999.
- Contato: confirme e substitua e-mail, cidade/endereço e horário de atendimento.
- Áreas de atuação: os três cards são provisórios. Confirme as áreas reais de atuação da profissional antes de publicar.
- SEO: revise título, descrição, conteúdo e dados de contato antes da publicação.

FORMULÁRIO
O formulário valida os campos obrigatórios e, depois de configurar o WhatsApp, prepara uma mensagem para abrir no WhatsApp. Não salva informações nem envia dados para um servidor. Para captação profissional de leads, será necessário configurar um backend ou serviço de formulários e uma política de privacidade adequada.
